# Picksync Frontend

Beautiful React + Vite frontend with premium design.

## Features

- 🎨 Glassmorphism UI with gradient effects
- ⚡ Framer Motion animations
- 📊 Live stats dashboard
- 🔥 Dark mode aesthetic
- 💎 Smooth UX

## Setup

```bash
npm install
```

## Environment

Create `.env`:
```
VITE_API_URL=http://localhost:3001
```

## Run

```bash
npm run dev
```

Open http://localhost:3000

## Build for Production

```bash
npm run build
```

## Deploy to Vercel

1. Push to GitHub
2. Import on Vercel
3. Set `VITE_API_URL` to your backend URL
4. Deploy!

## Tech Stack

- React 18
- Vite
- Tailwind CSS
- Framer Motion
- Lucide Icons
